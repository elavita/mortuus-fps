# MORTUUS 复刻版

浏览器里运行的**回合制僵尸生存 FPS**，单机 + 3 名 AI 队友。
基于 Three.js r169，**零外部美术/音频素材**——所有纹理、模型、音效都是程序实时生成的。

> 参考原作：Hamuno 的《Mortuus》（Steam 2026 年 10 月新品节 Demo，95% 好评）。
> 本项目是学习性质的技术复刻，不是原作分发。

**在线试玩**：<https://elavita.github.io/mortuus-fps/>

---

## 运行

### 在线
直接打开 <https://elavita.github.io/mortuus-fps/>

### 本地
游戏用 ES Module，**必须通过本地 HTTP 服务器打开**，直接双击 html 打不开。

```bash
cd src
python -m http.server 8777
```

然后浏览器打开 <http://127.0.0.1:8777>。Windows 下也可以直接双击 `启动游戏.bat`。

推荐最新版 Chrome / Edge，开独立显卡。帧数低就在「设置」里调低画质。

## 玩法

### 核心循环

```
回合开始 → 刷怪 → 击杀赚点数（掉落+连杀奖励）→ 回合结束
   → 三选一强化卡 → 军需站（买枪/买配件/补给/Perk/抽卡）→ 下一回合
```

每局地图都会重建：房间、走廊、门、Perk 机、神秘箱的位置全都不固定。

### 点数（货币）

| 来源 | 点数 |
|---|---|
| 命中僵尸 | +10 |
| 击杀 | +50 |
| 爆头击杀 | +100 |
| 近战击杀 | +130 |
| 回合结束 | +100 × 回合数 |
| **僵尸掉落** | 走近自动吸附，爆头必掉 60–100 |
| **连杀奖励** | 连杀 ≥3 时额外 +30 起，最高 +150 |
| **开神秘箱返还** | 300–800 |

### 军需站（回合间商店）

三选一选完卡后自动弹出，按 Esc 或点「跳过」直接进下一回合。

| 页签 | 内容 |
|---|---|
| **军需购买** | 8 把武器、8 类共 30+ 配件（按槽位分组） |
| **背包仓库** | 装配武器与配件，实时属性对比 |
| **补给** | 补弹药、回满血 |
| **Perk** | 厚血 / 快手 / 疾行 / 双发 / 鹰眼 |
| **抽卡** | 花点数额外抽一组强化卡 |

### 背包 / 仓库系统

**买的东西先进仓库，再到「背包仓库」组装。**

- 携带 2 个武器槽位，仓库里所有买过的武器随时可换
- 每把枪 8 个配件槽位，最多装 5 个配件
- 配件有库存数量，装在 A 枪上就不能同时装 B 枪
- 装配界面实时显示属性对比条（绿色变强 / 红色变弱）

### 瞄准镜（真正可用）

| 瞄具 | 倍率 | 表现 |
|---|---|---|
| 机械瞄具 | 1.0x | 照门对齐 |
| MRS 红点镜 | 1.35x | 红色圆点 + 细环，随开镜渐显 |
| 全息瞄准镜 | 1.4x | 红色圆环 + 中心点 |
| 4倍 ACOG | 3.0x | 全屏圆形镜片，三角分划 |
| 热成像瞄具 | 2.5x | 镜片遮罩 + 热成像滤镜 |
| 高倍狙击镜 | 7.0x | 大镜片，十字分划 |

高倍镜 ADS 时隐藏枪身、全屏镜内放大；低倍镜保留枪身、叠加准星。

### 三名 AI 队友

| 队友 | 定位 | 武器 |
|---|---|---|
| 布雷克 | 突击 | M4A1 |
| 渡鸦 | 狙击 | SKS |
| 维克丝 | 支援 | M870 |

会跟随、自动交火、保持队形不挡视线。**被打倒会倒地流血，靠近按住 F 救起**；不管会阵亡，下一回合自动归队。

### 僵尸

- **行尸**：基础款，从地面钻出
- **奔尸**（3 回合起）：冲刺追击
- **重装尸**（8 回合起）：6.5 倍血
- **臂行者**（10 回合起）：没腿，用手臂跑
- **爬行尸**（12 回合起）：从天花板扑下

**打腿会把腿打断**，之后只能爬。

## 技术要点

- **地图生成**：9×9 格网 → 预设房间布局随机放置 → Prim 最小生成树挖 L 形走廊 → 逐格判定建墙与门洞
- **门只挡玩家**：碰撞体带 `playersOnly` 标记，僵尸与队友穿过，导航网格也忽略门
- **断肢**：命中分 `head / body / legs`，腿部累计伤害超阈值即断腿转爬行
- **背包**：配件有库存计数，装配时检查可用数量，卸下自动回库
- **强化卡**：`baseStats` 快照 + 乘区计算，避免重复叠加污染原始属性
- **瞄准镜**：FOV 按倍率反算，高倍镜走全屏镜片遮罩、低倍镜走准星叠加
- **性能**：几何按材质合并、僵尸模型共享材质、粒子系统固定上限

## 已知限制

- 单机，没有联机
- 12 把武器（原作 30+）
- 没有剧情任务、彩蛋和 Boss「Mother」
- 没有「电源开关」机制（Perk 机默认可用）
